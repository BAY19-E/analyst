# работа с анализом базы данных музыкального магазина на SQL

## Задача состоит в том, чтобы проанализировать базу данных музыкального магазина Chinook с помощью SQL, найти ключевые бизнес-инсайты

## Вопросы, решенные с помощью SQL

### 1. Кто клиенты?
Посмотрела первые 10 записей клиентов

### 2. Откуда приходят клиенты?
Сгруппировала клиентов по странам. Больше всего клиентов из США, Канады, Великобритании

### 3. Какие самые дорогие покупки?
Нашла топ-5 самых больших счетов

### 4. Что покупают клиенты из Германии?
С помощью JOIN соединила 4 таблицы и получила список треков, купленных немецкими клиентами

### 5. Кто самые ценные клиенты?
С помощью оконной функции RANK() определила топ-10 клиентов по сумме покупок

## Вывод
База данных Chinook содержит информацию о продажах музыкального магазина. С помощью SQL можно находить ценных клиентов, популярные товары и анализировать географию продаж.
