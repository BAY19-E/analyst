# Работа по анализу чаевых, оставленных в ресторане 
## Задача заключается в том, чтобы понять от чего зависит размер чаевых для улучшения сервиса 
## В данных содержатся 244 наблюдения по 7 признакам: счет, чаевые, пол, курящие или нет, день недели, обед или ужин, количество посетителей
## Я посчитала средний чек и чаевые, посмотрела верхушку таблицы, построила график зависимости чаевых от суммы счета
## По результатам средний чек составил 19.79 долларов, а средние чаевые — 2.99. Зависимость положительная
## Для получения большего количества чаевых ресторан может предлагать более дорогие позиции меню. К примеру, с помощью рекомендаций персонала или рекламы в социальных сетях, направленной на появления тренда на некоторые позиции
## График и код представлены в папках 'notebooks' и 'visualizations'
